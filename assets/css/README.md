# CSS

## Folhas atuais

- `app.css`: estilos principais do sistema.
- `style.css`: estilos gerais/legados.
- `professional.css`: ajustes visuais adicionais.
- `premium.css`: estilos adicionais.
- `auth-legacy.css`: estilos legados de autenticação.
- `catalogo.css`: catálogo público.

## Direção

O projeto possui estilos históricos sobrepostos. Antes de criar outro arquivo CSS, procure uma regra existente.

A futura organização deve separar:

- base;
- layout;
- componentes;
- páginas;
- catálogo;
- autenticação.

A migração deve ser feita em pequenas etapas e testada a cada etapa.
